# Rusted Warfare 模组开发支持插件

这个 VS Code 插件为 Rusted Warfare 游戏模组开发提供支持，包括代码补全、语法提示等功能。

## 功能特性

- 为 Rusted Warfare 模组文件提供智能代码补全
- 支持多种模组配置节（sections）的语法高亮和提示
- 提供参数补全和值补全功能
- 支持中英文界面显示

## 构建和打包

### 环境要求

- Node.js >= 22.x
- npm 或 bun（推荐使用 bun 以获得更好的性能）

### 安装依赖

使用 npm:
```bash
npm install
```

或者使用 bun (推荐):
```bash
bun install
```

### 开发模式

在开发过程中，可以使用以下命令:

```bash
# 编译项目
npm run compile

# 监听模式编译
npm run watch
```

### 打包发布

要打包插件用于发布，运行:

```bash
npm run package
```

### 运行测试

```bash
npm run test
```
